Everything runs through Expanso Edge. No isolated scripts, no unversioned code.

Data Flow

All events follow a single path: Camera → Inference (YOLO-World) → Expanso Edge enrichment → Archive + Upstream. The dashboard reads state produced by the pipeline. No data bypasses Expanso.

Events are schema-versioned (v1.0.0), self-describing, and mergeable across cameras and sites via session_id and site_id fields.

Deployment

Pipelines deploy from cloud.expanso.io to the edge node. The CLI command:

expanso-cli job deploy jobs/security-camera-events-job.yaml

Expanso Cloud pushes the job to the Jetson. The agent starts the subprocess, monitors health, restarts on failure. Version updates are a new job deploy.
